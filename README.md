# My Digital Devices

A personal archive for the phones, computers, displays and XR devices I own and use.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Current collection

The first version includes 10 devices across five categories:

- Phones
- Laptops
- Desktop
- Displays
- XR

Device data lives in `data/devices.ts`, so adding a new device only requires a new data object. Detail pages are generated automatically from that collection.

## Roadmap

Planned follow-ups include device photos, purchase dates and prices, ownership status/history, richer specifications, filtering/search, timeline views and deployment to Vercel.
